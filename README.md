# Rynote

Advanced Discord music bot with filters, playlists, lyrics, autoplay & multi-language support.

## Features

- Play music from YouTube, Spotify, SoundCloud, Deezer & more
- 10 built-in audio filters (Bassboost, Nightcore, Television, etc.)
- Playlist system with public/private visibility
- Synced & plain lyrics display
- 24/7 voice channel mode
- Multi-language support (English & Indonesian)
- Song request channel with setup wizard
- Real-time now-playing updates
- Auto-reconnect & queue management

## Quick Start

```
.play <song>      # Play a song
.filter bassboost # Apply audio filter
.lyrics           # Show lyrics
.setup            # Create song request channel
.247              # Toggle 24/7 mode
.lang id          # Switch to Indonesian
.help             # List all commands
```
